## How it works

`interaction: { keyboard: true }` makes the element focusable and moves the focus with the arrow keys, toward the nearest node in that direction. The built-in `focused` state is overridden with a wider outline, a halo and a label, so the focus is easy to follow.

The example listens to `focuschange` and `selectionchange` to describe the focused node in the status. After the first frame, `graph.focus.set` puts the focus on a node so the graph is ready for the keys.

## Try it

- Press the arrow keys to move the focus from node to node.
- Press Enter or Space to select the focused node, with Shift to add it.
- Hold Shift and press the arrow keys to pan, press + and - to zoom, and 0 to fit.
- Press Escape to clear the selection, then once more to drop the focus.
