## How it works

The React state holds a moment. `<Graph time={{ start: moment, end: moment }}>` passes it as a controlled window: with `start` equal to `end`, the window is a single moment, and the graph shows the periods that contain it.

The slider is a plain range input over the extent of the data, one day per step. Inside `<Graph>`, `useTimeline` counts the nodes over time without drawing anything: the bars come from `state.bins`, and the bar of the current moment takes the accent color.

`onTimeChange` keeps the state in step if anything else asks for a new window, such as `graph.time.set`. After the layout, `useGraphEvent('layoutend')` frames the graph again with room for the slider.

## Try it

- Drag the slider across the years.
- Focus the slider and press the arrow keys to move a day at a time.
- Run `graph.time.set({ start: Date.UTC(2023, 0, 1) })` in the console: the graph asks for that window, the handler keeps its start as the new moment, and the slider follows.
