## How it works

The example keeps its pins in a `Map` of positions, read by the `x` and `y` channels: a pinned node has a position in the data, a free node has none. A layout never moves a node placed by its data, so each time the pins change, the example passes a new definition to `graph.update` and `graph.layout.run()` settles the free nodes around the pinned ones. A free state, `pinned`, outlines them.

On `dragend`, the dragged nodes join the map at the position where they were dropped. On `doubleclick`, a pinned node leaves it: its `x` and `y` become empty, and the layout moves it again. When the first layout ends, the three largest nodes are pinned on a triangle: they glide there, and the layout already arranges the other nodes around their final places.

## Try it

- Drag a node away: it stays where you drop it and the rest follows.
- Drag a few more to shape the graph.
- Double-click a pinned node to release it.
