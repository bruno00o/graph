```ts
import { createMinimap } from '@bruno00o/graph/minimap'

function createMinimap<S extends string, M extends Mark>(
  graph: GraphInstance<S, M>,
  options?: MinimapOptions,
): Minimap
```

Creates the minimap of a graph made by [`mountGraph`](/docs/api/mount-graph). See [Minimap and legend](/docs/minimap-and-legend#minimap) for a walkthrough.

## Minimap component

```ts
import { Minimap } from '@bruno00o/graph/react'

function Minimap(props: MinimapProps): ReactNode
```

Use it inside the children of [`<Graph>`](/docs/api/graph-component), or anywhere with the `graph` prop, which wins over the graph in context. Without a graph from either, it throws; `graph: null` draws nothing until a graph is given. Its props are the options above, and `graph`. With a `corner`, it renders nothing where it stands and sits in the graph element; with `corner={null}`, it renders a `div` that holds the minimap.

## Errors

- A graph that was not created by `mountGraph` throws an `Error`.

## Behavior

- The element carries `data-graph-minimap` and `aria-hidden="true"`. The rectangle of the view carries `data-view`.
- Colors are CSS colors, `--graph-…` tokens included, resolved with the current theme and again when it changes.
- The minimap frames every node and group container. A view larger than the graph shows its rectangle cut by the edges of the minimap.
- Drawing happens in a worker when the browser has `Worker`, `OffscreenCanvas` and `ImageBitmapRenderingContext` and the page allows `worker-src blob:`; otherwise on the page, at the same pace.
- On a graph made by `mountMapGraph`, the minimap draws nothing: its element stays empty and out of the graph element, it starts no worker, `update` does nothing, and a warning is logged once in development.
- Destroying the graph destroys its minimaps. A minimap created on a destroyed graph comes back destroyed: it holds no worker, observer or timer, and draws nothing.
