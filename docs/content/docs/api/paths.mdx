```ts
interface GraphPaths<M extends Mark = Mark> {
  shortest(from: Key, to: Key, options?: PathOptions<M>): GraphPath | null
  reach(from: Key, options?: ReachOptions<M>): GraphReach
}

function createPathFinder<M extends Mark>(definition: { marks: readonly M[] }): PathFinder<M>
```

`graph.paths` is a `GraphPaths` on every [`GraphInstance`](/docs/api/graph-instance). `M` is the union of the marks: it types the fields and the items that `weight`, `nodes` and `edges` read. See [Paths](/docs/paths).

## createPathFinder

```ts
import { createPathFinder, edges, nodes } from '@bruno00o/graph'

const paths = createPathFinder({
  marks: [nodes<Item>(items), edges<Link>(links, { source: 'from', target: 'to' })],
})
const path = paths.shortest('a', 'f', { weight: 'distance' })
paths.destroy()
```

It takes the marks of a definition, or a definition itself, and runs the same queries without mounting a graph. It reads the arrays and subscribes to the live sources as soon as it is created, and applies their changes at the next query. `visible` has no effect: there is nothing drawn. After `destroy`, `shortest` returns `null` and `reach` the same empty, frozen result as for an unknown key.

## Errors

- `RangeError` when `maxCost` is not a number of 0 or more, or when an edge weighs less than 0.
- `TypeError` when `direction` is not `'both'`, `'forward'` or `'backward'`.
