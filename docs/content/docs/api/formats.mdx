title: Formats
description: Read and write GraphML, GEXF, JSON Graph Format and CSV files.
---

```ts
import { readGraphml, writeGexf } from '@bruno00o/graph/formats'
```

Readers turn the text of a file into plain nodes and edges for the marks, writers turn any nodes and edges into text. Nothing is fetched and nothing is imported: you load the file and save the text. See [File formats](/docs/file-formats) for a walkthrough.

## Reading

```ts
function readGraphml<N extends object = FileAttributes, E extends object = FileAttributes>(
  text: string,
  options?: ReadOptions,
): GraphFile<N, E>

function readGexf<N extends object = FileAttributes, E extends object = FileAttributes>(
  text: string,
): GraphFile<N, E>

function readJsonGraph<N extends object = FileAttributes, E extends object = FileAttributes>(
  input: string | object,
  options?: JsonGraphReadOptions,
): GraphFile<N, E>

function readJsonGraphs<N extends object = FileAttributes, E extends object = FileAttributes>(
  input: string | object,
  options?: ReadOptions,
): GraphFile<N, E>[]

function readCsv<N extends object = FileAttributes, E extends object = FileAttributes>(
  tables: CsvTables | string,
  options?: CsvReadOptions,
): GraphFile<N, E>

function detectFormat(text: string): GraphFormat | null
```

`N` and `E` type the `attributes` of the nodes and of the edges. It is an assertion, like the type of `JSON.parse`: the file is not checked against it. `readCsv` takes a single string as the edge table. `detectFormat` looks at the first characters of a text and returns `null` when it recognizes none.

## Errors

```ts
class FormatError extends Error {
  readonly format: GraphFormat
  readonly line: number | undefined
  readonly column: number | undefined
}
```

A reader throws a `FormatError` only when it cannot read the file at all: XML that is not well formed, a root element of another format, JSON that does not parse, a CSV table without its id, source or target column, or a quoted field that never closes. The message names the format and, when there is one, the line and the column, such as `graphml: expected </node>, found </graph> at line 12, column 5`. Every other problem goes to `issues`.

## Writing

```ts
function writeGraphml<N, E>(input: GraphInput<N, E>, options?: WriteOptions<N, E>): string

function writeGexf<N, E>(input: GraphInput<N, E>, options?: GexfWriteOptions<N, E>): string

function writeJsonGraph<N, E>(input: GraphInput<N, E>, options?: JsonGraphWriteOptions<N, E>): string

function writeJsonGraphs<N, E>(
  inputs: readonly GraphInput<N, E>[],
  options?: JsonGraphWriteOptions<N, E>,
): string

function writeCsv<N, E>(input: GraphInput<N, E>, options?: CsvWriteOptions<N, E>): CsvFiles
```

A writer throws a `TypeError` for a node without key and for an edge without source or target.
