---
title: nodes
description: A mark that draws one node per item of its data.
---

```ts
function nodes<T>(data: LiveSource<T>, options?: NodeOptions<T>): NodeMark<T>
function nodes<T extends { readonly id: Key }>(data: Iterable<T>, options?: NodeOptions<T>): NodeMark<T>
function nodes<T>(data: Iterable<T>, options: NodeOptions<T> & { key: KeyChannel<T> }): NodeMark<T>
```

`key` is required for an iterable whose items have no `id` field. A live source carries its keys in its changes.

## Options

A **channel** is a field name or a function, and goes through a scale. A **style** is a constant or a function, with no scale. See [Marks and channels](/docs/marks).

<api-table path="index.ts" name="NodeOptions" />

`outline` alone draws a 2 pixel ring. `outlineWidth` alone draws the ring in `--graph-node-ring`.

## Groups

A node whose `parent` is the key of another node is a child of that node, which becomes a group. Groups nest. See [Groups](/docs/groups).

```ts
type ContainerShape = 'rectangle' | 'circle'

interface ContainerOptions<T> {
  readonly shape?: Style<T, ContainerShape>
  readonly padding?: Style<T, number>
  readonly fill?: Style<T, string>
  readonly stroke?: Style<T, string>
  readonly strokeWidth?: Style<T, number>
}
```

<api-table path="index.ts" name="ContainerOptions" />

- An unfolded group draws its container behind its children, sized to them and moved with them. Its label sits above the container by default. Its other options apply when it is folded.
- A `parent` that names no node is reported in `issues` as `missing-parent`, and the node stays at the top level until that node arrives. A `parent` that would make a node contain itself is reported as `parent-cycle`, and that node stays at the top level.

## Types

```ts
type Key = string | number
type Accessor<T, V> = (datum: T) => V
type Channel<T, V> = FieldOf<T, V> | Accessor<T, V | null | undefined>
type KeyChannel<T> = KeyFieldOf<T> | Accessor<T, Key>
type Style<T, V> = V | Accessor<T, V>
```

`FieldOf<T, V>` is the union of the keys of `T` whose values are `V`, `null` or `undefined`. `KeyFieldOf<T>` is the union of the required keys of `T` whose values are keys.
