```ts
function nodes<T, N extends MarkName = undefined, L extends MarkLayer = undefined>(
  data: LiveSource<T>,
  options?: NodeOptions<T, N, L>,
): NodeMark<T, N, L>
function nodes<
  T extends { readonly id: Key },
  N extends MarkName = undefined,
  L extends MarkLayer = undefined,
>(
  data: Iterable<T>,
  options?: NodeOptions<T, N, L>,
): NodeMark<T, N, L>
function nodes<T, N extends MarkName = undefined, L extends MarkLayer = undefined>(
  data: Iterable<T>,
  options: NodeOptions<T, N, L> & { key: KeyChannel<T> },
): NodeMark<T, N, L>
```

`T` is the item type, inferred from `data`, and `N` the type of `name`, `undefined` without one. Both type the targets of the nodes in events and in the state: see [TypeScript](/docs/typescript). `L` is the type of `layer`, `undefined` without one: it types the layer names of the instance, see [Multilayer graphs](/docs/multilayer).

`key` is required for an iterable whose items have no `id` field. A live source carries its keys in its changes.

## Options

A **channel** is a field name or a function, and goes through a scale. A **style** is a constant or a function, with no scale. A number literal and a function wrapped in [`raw()`](#types) skip the scale. See [Marks and channels](/docs/marks#channels-and-styles).

<api-table path="index.ts" name="NodeOptions" />

`outline` alone draws a 2 pixel ring. `outlineWidth` alone draws the ring in `--graph-node-ring`.

With `shape: 'box'`, `size` is the height of the box and `width` its width: `'label'` fits the width to the label, a number sets it. `cornerRadius` rounds the corners. See [Boxes](/docs/marks#boxes).

## Groups

A node whose `parent` is the key of another node is a child of that node, which becomes a group. Groups nest. See [Groups](/docs/groups).

```ts
type ContainerShape = 'rectangle' | 'circle'

interface ContainerOptions<T> {
  readonly shape?: Style<T, ContainerShape>
  readonly padding?: Style<T, number>
  readonly fill?: Style<T, string>
  readonly stroke?: Style<T, string>
  readonly strokeWidth?: Style<T, number>
}
```

<api-table path="index.ts" name="ContainerOptions" />

- An unfolded group draws its container behind its children, sized to them and moved with them. Its label sits above the container by default. Its other options apply when it is folded.
- A `parent` that names no node is reported in `issues` as `missing-parent`, and the node stays at the top level until that node arrives. A `parent` that would make a node contain itself is reported as `parent-cycle`, and that node stays at the top level.

## Types

```ts
type Key = string | number
type Accessor<T, V> = (datum: T) => V
type Channel<T, V> = FieldOf<T, V> | Accessor<T, V | null | undefined>
type NumberChannel<T> = Channel<T, number> | number | RawAccessor<T, number | null | undefined>
type ColorChannel<T> = Channel<T, string | number | boolean> | RawAccessor<T, string | null | undefined>
type KeyChannel<T> = KeyFieldOf<T> | Accessor<T, Key>
type Style<T, V> = V | Accessor<T, V>

function raw<T, V>(read: Accessor<T, V>): RawAccessor<T, V>
```

`FieldOf<T, V>` is the union of the keys of `T` whose values are `V`, `null` or `undefined`. `KeyFieldOf<T>` is the union of the required keys of `T` whose values are keys.

`raw()` returns a `RawAccessor<T, V>`, a function of the item marked so that its value skips the scale of its channel. It works on `size` and `color` here, on `width` and `color` of [edges](/docs/api/edges) and of their ends. A raw size is a diameter in pixels, a raw color a CSS color. Raw values stay out of the extent and the categories of the scale, and a raw color has no category in the [legend](/docs/api/legend). Any other value throws a `TypeError`.
