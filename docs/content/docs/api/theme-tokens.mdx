---
title: Theme tokens
description: Every CSS variable of the default theme, with its light and dark values.
---

`@bruno00o/graph/theme.css` sets these variables on `:root`, `.light` and `[data-theme="light"]` for the light theme, and on `.dark`, `[data-theme="dark"]` or under `prefers-color-scheme: dark` for the dark theme. Override any of them in your own CSS. See [Theming](/docs/theming).
