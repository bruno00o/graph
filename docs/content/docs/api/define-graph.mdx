---
title: defineGraph
description: Build a frozen graph definition from marks, scales, states and options.
---

```ts
function defineGraph<S extends string = never, M extends Mark = never>(
  options: GraphDefinitionOptions<S, M>,
): GraphDefinition<S, M>
```

Returns a frozen definition. `S` is inferred from the keys of `states` and types the state methods of the instance. `M` is inferred from `marks`, the union of their types: the item types and names of the marks type the targets of events and of the state. See [TypeScript](/docs/typescript).

## Layout

`layout` takes a `Layout`, such as the result of [`force()`](/docs/api/force) or [`grid()`](/docs/api/layouts), or `null`. The port is public: any object with this shape works. See [Write your own layout](/docs/layout#write-your-own-layout).

```ts
interface Layout {
  readonly name: string
  readonly options: object
  readonly incremental?: boolean
  start(graph: LayoutGraph, listener: LayoutListener): LayoutRun
}

interface LayoutGraph {
  readonly capacity: number
  readonly alive: Uint8Array
  readonly movable: Uint8Array
  readonly xy: Float32Array
  readonly radius: Float32Array
  readonly edges: Uint32Array
  readonly keys: readonly (Key | undefined)[]
  datum(index: number): unknown
}

interface LayoutListener {
  progress(xy: Float32Array, progress: number): void
  end(xy: Float32Array): void
}

interface LayoutRun {
  pin(index: number, x: number, y: number): void
  stop(): void
}
```

## Background

`background: { grid }` draws a grid under everything, on the canvas, so it follows pan and zoom. The canvas stays transparent: the page still paints `--graph-paper` behind it.

<api-table path="index.ts" name="BackgroundOptions" />

The grid has three levels, `spacing` times a power of 4 apart, chosen from the zoom. The finest level fades in as its lines grow from 4 to 16 pixels apart, and lines of the coarser levels blend into `majorColor`, so zooming never shows a jump. See [Drawing layers](/docs/drawing-layers#background-grid).

## Hulls

`hulls` takes the results of [`hull()`](/docs/api/hull), drawn under edges and nodes in their order. A hull that follows a state must name a declared state, or `selected`, `hovered` or `focused`.

## Errors

- `TypeError` when a mark does not come from `nodes()` or `edges()`, or when `interaction.wheel` is not `'zoom'`, `'pan'` or `'page'`.
- `RangeError` when `view.minZoom` is not positive, `view.maxZoom` is not finite or is smaller than `minZoom`, or `view.bounds` holds a value that is not finite or a rectangle whose minimum exceeds its maximum.
- `TypeError` when `background.grid` is not `'lines'` or `'dots'`, or when a hull does not come from `hull()`.
- `RangeError` with more than 29 states besides `selected`, `hovered` and `focused`.

## Result

```ts
interface GraphDefinition<S extends string = string, M extends Mark = Mark> {
  readonly marks: readonly M[]
  readonly scales: ScalesOptions
  readonly states: StateStyles<S>
  readonly layout: Layout<NodeDatum<M>> | null
  readonly interaction: ResolvedInteraction
  readonly view: ResolvedViewLimits
  readonly transitions: ResolvedTransitions
  readonly background: ResolvedBackground | null
  readonly hulls: readonly Hull[]
}
```

Options are resolved: `interaction.zoom` and `interaction.autoPan` are `false` or `{ speed }`, `view` holds `minZoom`, `maxZoom` and `bounds` (`null` without bounds), `transitions.positions` and `transitions.layout` are numbers of milliseconds, and `background` is `null` or carries its spacing and colors.
