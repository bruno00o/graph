`set` also moves the DOM focus to the graph element when the keyboard is on. An unknown key changes nothing.

## States

```ts
interface GraphStates<N extends string> {
  set(name: N, keys: ElementKeysInput): void
  add(name: N, keys: ElementKeysInput): void
  remove(name: N, keys: ElementKeysInput): void
  clear(name?: N): void
  has(name: N, element: { kind: 'node' | 'edge'; key: Key }): boolean
}
```

<api-table path="index.ts" name="GraphStates" />

`N` is the union of the free state names of the definition. Built-in and undeclared names are refused, at compile time and at runtime. `clear()` without a name empties every free state.

## Positions

```ts
interface GraphPositions {
  get(key: Key): Point | undefined
  set(entries: Iterable<readonly [Key, Point]>, options?: { duration?: number }): void
}
```

Positions are in world units. `set` emits `positionchange` with the origin `'api'`. During a layout run, the nodes moved by `set` are pinned until the run ends.

## Layout

```ts
interface GraphLayout {
  run(layout?: Layout, options?: LayoutRunOptions): Promise<boolean>
  stop(): void
}

interface LayoutRunOptions {
  readonly keys?: Iterable<Key>
  readonly fit?: boolean | FitOptions
  readonly duration?: number
}
```

`run` applies pending data changes, stops the current run, then lays out every free node, or only `keys`, with `layout` or the layout of the definition. It resolves to `true` when the run ends and `false` when it is stopped, replaced or the graph is destroyed. It rejects when there is no layout to run. `stop` ends the current run and leaves nodes where they are. See [Layouts](/docs/layout).

## Graph state

```ts
interface GraphState<S extends string = string> {
  readonly view: View
  readonly width: number
  readonly height: number
  readonly hovered: GraphTarget | null
  readonly focused: GraphTarget | null
  readonly selection: ElementKeys
  readonly states: { readonly [K in FreeState<S>]: ElementKeys }
  readonly positionsVersion: number
  readonly layout: GraphLayoutStatus
  readonly folded: readonly Key[]
}

interface GraphLayoutStatus {
  readonly running: boolean
  readonly progress: number
}
```

<api-table path="index.ts" name="GraphState" />

`width` and `height` are the size of the graph in CSS pixels. `positionsVersion` changes whenever a position changes; read the positions themselves with `positions.get`. `layout.progress` goes from 0 to 1 during a run.
