description: Load neighborhoods on demand with TanStack Query and expose them as live sources.

```ts
import { createExploration } from '@bruno00o/graph/query'

function createExploration<TNode, TEdge>(
  client: QueryClient,
  options: ExplorationOptions<TNode, TEdge>,
): Exploration<TNode, TEdge>
```

Items are keyed by their `id` field unless `nodeKey` or `edgeKey` says otherwise, with a field name or a function. Without `nodeKey`, `TNode` must have an `id` field, and the same for `TEdge` without `edgeKey`. When a key is a function, give `neighbors` before it in the options, so that it reads typed items.

An item whose key is neither a string nor a finite number is skipped by the graph and listed as a `missing-key` problem by `graph.issues()`.

Observers only run while a source has a subscriber, so creating an exploration fetches nothing until a mark using it is mounted.

`retry` refetches an expansion whose query failed, with `refetch` of its observer, and leaves its key out of `errors` until that fetch fails again. It does nothing for a key that is not expanded or has not failed, and waits for a subscriber before fetching.
