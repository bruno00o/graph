---
title: edges
description: A mark that draws one edge per item of its data.
---

```ts
function edges<T, N extends MarkName = undefined>(
  data: LiveSource<T>,
  options: EdgeOptions<T, N>,
): EdgeMark<T, N>
function edges<T extends { readonly id: Key }, N extends MarkName = undefined>(
  data: Iterable<T>,
  options: EdgeOptions<T, N>,
): EdgeMark<T, N>
function edges<T, N extends MarkName = undefined>(
  data: Iterable<T>,
  options: EdgeOptions<T, N> & { key: KeyChannel<T> },
): EdgeMark<T, N>
```

`source` and `target` are required. An edge whose two ends are not both present waits until they are. `T` is the item type and `N` the type of `name`: both type the targets of the edges, see [TypeScript](/docs/typescript).

## Labels

```ts
interface EdgeLabelOptions<T> extends LabelTextOptions<T> {}
```

`EdgeLabelOptions` has the text options of a node label: `text`, `background`, `color`, `size`, `weight`, `font` and `maxWidth`. See [`LabelTextOptions`](/docs/api/nodes#labels). The default size is 11.

<api-table path="index.ts" name="EdgeLabelOptions" />

- The label sits halfway along the edge, on the arc of a curved edge, and turns with it while staying upright.
- Without a background, it sits above the line. With one, it is centered on the line.
- It shows only when it fits between the two nodes. The hovered or focused edge shows it over other labels.

```ts
edges<Link>(links, {
  source: 'from',
  target: 'to',
  label: { text: 'name', size: 10, color: 'var(--graph-ink-muted)', background: true },
})
```

## Parallel edges and loops

Edges that share the same two nodes, in either direction, bend apart in symmetric arcs; an edge alone on its pair stays straight. An edge from a node to itself is a loop, and several loops nest. There is no option for the curvature yet.

## Edges of folded groups

An end inside a folded group is drawn at the outermost folded group that holds it. The edges of one mark that land on the same two ends, in the same direction, draw as one aggregated edge; an edge whose two ends land in the same group is hidden. `aggregate` styles the aggregated edges from an `AggregateEdge`, the merged edges with their count.

```ts
interface AggregateEdge<T = unknown> {
  readonly source: Key
  readonly target: Key
  readonly count: number
  readonly keys: readonly Key[]
  readonly data: readonly T[]
}

type AggregateEdgeOptions<T> = Omit<
  EdgeOptions<AggregateEdge<T>>,
  'name' | 'key' | 'source' | 'target' | 'aggregate'
>
```

<api-table path="index.ts" name="AggregateEdge" />

Without `aggregate`, an aggregated edge looks like its first merged edge, and shows a label only when it merges a single edge. Its `time` goes from the earliest start to the latest end of the merged edges, or is missing when one of them has none.

```ts
edges<Link>(links, {
  source: 'from',
  target: 'to',
  aggregate: {
    width: (aggregate) => aggregate.count,
    label: (aggregate) => (aggregate.count > 1 ? String(aggregate.count) : null),
  },
})
```

## Example

```ts
type Link = { id: string; from: string; to: string; kind: 'main' | 'side' }

edges<Link>(links, {
  source: 'from',
  target: 'to',
  color: 'kind',
  arrow: 'target',
  dash: (link) => (link.kind === 'side' ? 'dashed' : 'solid'),
})
```
