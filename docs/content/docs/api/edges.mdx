---
title: edges
description: A mark that draws one edge per item of its data.
---

```ts
function edges<T>(data: LiveSource<T>, options: EdgeOptions<T>): EdgeMark<T>
function edges<T extends { readonly id: Key }>(data: Iterable<T>, options: EdgeOptions<T>): EdgeMark<T>
function edges<T>(data: Iterable<T>, options: EdgeOptions<T> & { key: KeyChannel<T> }): EdgeMark<T>
```

`source` and `target` are required. An edge whose two ends are not both present waits until they are.

## Options

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `KeyChannel<T>` | `'id'` | Edge key |
| `source` | `KeyChannel<T>` | | Key of the source node |
| `target` | `KeyChannel<T>` | | Key of the target node |
| `color` | `Channel<T, string \| number \| boolean>` | `--graph-edge` | Value passed to the `color` scale |
| `width` | `Channel<T, number>` | `1.5` | Value passed to the `width` scale, in screen pixels |
| `label` | `Channel<T, string>` | | Label text |
| `dash` | `Style<T, 'solid' \| 'dashed' \| 'dotted'>` | `'solid'` | Line pattern |
| `arrow` | `Style<T, 'none' \| 'source' \| 'target' \| 'both'>` | `'none'` | Arrow heads |
| `stroke` | `Style<T, string>` | | Line color, wins over `color` |
| `opacity` | `Style<T, number>` | `1` | Opacity from 0 to 1 |

## Parallel edges and loops

Edges that share the same two nodes, in either direction, bend apart in symmetric arcs; an edge alone on its pair stays straight. An edge from a node to itself is a loop, and several loops nest. There is no option for the curvature yet.

## Example

```ts
type Link = { id: string; from: string; to: string; kind: 'main' | 'side' }

edges<Link>(links, {
  source: 'from',
  target: 'to',
  color: 'kind',
  arrow: 'target',
  dash: (link) => (link.kind === 'side' ? 'dashed' : 'solid'),
})
```
