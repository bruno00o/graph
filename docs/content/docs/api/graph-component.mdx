---
title: Graph
description: The React component that mounts a graph and renders overlays above it.
---

```tsx
import { Graph } from '@bruno00o/graph/react'

<Graph definition={definition} ariaLabel="Sample graph" style={{ height: 480 }} />
```

```ts
function Graph<S extends string = string, M extends Mark = Mark>(props: GraphProps<S, M>): JSX.Element
```

`S` and `M` come from `definition`: they type the targets of the event props and the instance given to `ref`. A ref object typed as a plain `GraphInstance` works too.

## Props

<api-table path="react/index.tsx" name="GraphProps" />

Each event prop receives the payload of the matching [event](/docs/api/events). The latest function passed is always called.

With `selection`, `onSelectionChange` receives selection requests and the graph only changes when `selection` does. `folded` and `onFoldChange` work the same way for [groups](/docs/groups), `view` and `onViewChange` for the [view](/docs/view#controlled-view), and `time` and `onTimeChange` for the [time window](/docs/time#controlled-window).

## Behavior

- The wrapping `div` is positioned relative. The graph fills it, and children render above the canvas. To pin a child to a node or an edge, wrap it in [`<Anchor>`](/docs/api/anchor).
- The graph mounts once, in a layout effect, and is destroyed on unmount. Under StrictMode, one instance remains.
- Children only render once the graph exists, so `useGraph` always returns an instance.
