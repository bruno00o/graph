```ts
function mountGraph<S extends string = string, M extends Mark = Mark>(
  container: HTMLElement,
  options: MountGraphOptions<S, M>,
): GraphInstance<S, M>
```

Appends the graph element to `container` and returns its [instance](/docs/api/graph-instance). The graph fills the container; give the container a size. `S` and `M` come from the definition.

## Signal

`signal` ties the graph to an `AbortController` of your own: the graph is destroyed when it aborts, and `graph.signal` aborts with the same reason. One controller can end a graph and the work around it at once.

```ts
const controller = new AbortController()
const graph = mountGraph(container, { definition, signal: controller.signal })
fetch(url, { signal: controller.signal })

controller.abort()
```

A signal already aborted mounts nothing: `mountGraph` returns a destroyed graph, adds no element to the container, and logs a warning in development. See [after destroy](/docs/api/graph-instance#after-destroy).

## The graph element

`graph.element` is the `div` added to the container. It holds the canvas and carries:

- `aria-label` from `ariaLabel`,
- `data-graph`,
- `role="application"` and `tabindex="0"` when the keyboard is on, `role="img"` otherwise,
- an outline in `--graph-focus-ring` when it has the keyboard focus and no node is focused.

The canvas is transparent: the page behind it is the background.
