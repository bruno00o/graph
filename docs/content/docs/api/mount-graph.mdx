```ts
function mountGraph<S extends string = string, M extends Mark = Mark>(
  container: HTMLElement,
  options: MountGraphOptions<S, M>,
): GraphInstance<S, M>
```

Appends the graph element to `container` and returns its [instance](/docs/api/graph-instance). The graph fills the container; give the container a size. `mountGraph` never changes the style of the container. `S` and `M` come from the definition.

The selection itself, as `onSelectionChange` receives it, is an [`ElementKeys`](/docs/api/graph-instance#selection).

`surface` takes a surface made by [`mapSurface`](/docs/api/map#mapsurface), to draw the graph inside a map instead of its own canvas. Given again to `update`, it moves the graph, with its positions and view kept for each surface. See [With and without a map](/docs/map#with-and-without-a-map).

## Suspended

`suspended: true` mounts the graph without a WebGL context: it reads its data, lays it out, answers every call and fills its store, and draws nothing until [`resume`](/docs/api/graph-instance#suspend). Mount the graphs of a long page this way and resume each one as it comes into sight, so that the page asks for no more contexts than the graphs it shows.

```ts
const graph = mountGraph(card, { definition, ariaLabel: 'Sample graph', suspended: true })
new IntersectionObserver(([entry]) => {
  if (entry?.isIntersecting) graph.resume()
  else graph.suspend()
}).observe(card)
```

`keepFrame: false` keeps no copy of the last frame while the graph is suspended: it saves width × height × pixel ratio² × 4 bytes for each suspended graph, and the page shows an empty box until `resume` draws again. It defaults to `true`, and `update` changes it. See [Suspend](/docs/api/graph-instance#suspend).

## Signal

`signal` ties the graph to an `AbortController` of your own: the graph is destroyed when it aborts, and `graph.signal` aborts with the same reason. One controller can end a graph and the work around it at once.

```ts
const controller = new AbortController()
const graph = mountGraph(container, { definition, signal: controller.signal })
fetch(url, { signal: controller.signal })

controller.abort()
```

A signal already aborted mounts nothing: `mountGraph` returns a destroyed graph, adds no element to the container, and logs a warning in development. See [after destroy](/docs/api/graph-instance#after-destroy).

## The graph element

`graph.element` is the `div` added to the container. It holds the canvas and carries:

- `aria-label` from `ariaLabel`,
- `data-graph`,
- `role="application"` and `tabindex="0"` when the keyboard is on, `role="img"` otherwise,
- an outline in `--graph-focus-ring` when it has the keyboard focus and no node is focused.

The canvas is transparent: the page behind it is the background.
