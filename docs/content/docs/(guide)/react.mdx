`@bruno00o/graph/react` wraps the core in a component and three hooks. It needs React 19. `@bruno00o/graph/map/react` adds [`<MapGraph>`](#maps), for a graph inside a MapLibre map.

## The Graph component

```tsx title="SampleGraph.tsx"
import { defineGraph, edges, nodes } from '@bruno00o/graph'
import { Graph } from '@bruno00o/graph/react'
import { useMemo } from 'react'

export function SampleGraph({ items, links }: { items: Item[]; links: Link[] }) {
  const definition = useMemo(
    () =>
      defineGraph({
        marks: [
          edges(links, { source: 'from', target: 'to' }),
          nodes(items, { color: 'group', label: 'label' }),
        ],
      }),
    [items, links],
  )
  return <Graph definition={definition} ariaLabel="Sample graph" style={{ height: 480 }} />
}
```

- `<Graph>` renders a `div` in relative position, sized by your `className` or `style`, with the graph inside.
- Build the definition with `useMemo`, or outside the component. A new definition is applied with `update`, so positions, view and selection stay.
- Declare the functions of mark options, such as `label: (item) => item.name`, outside the component. Options are compared by content, but functions by identity: a new function restyles every item of its mark. See [Update the data](/docs/data#update-the-data).
- The graph is mounted once and destroyed on unmount. StrictMode mounts, destroys and mounts again: one instance remains.

Every prop, with the event props, is listed in [`<Graph>`](/docs/api/graph-component#props).

Event props always call the latest function you pass, without subscribing again.

## Overlays

Children of `<Graph>` are HTML drawn over the canvas. They can read and drive the graph through the hooks. To pin an element to a node, an edge or a point, wrap it in `<Anchor>`: it follows the view and the node without rendering again.

```tsx title="Tooltip.tsx"
import type { EdgeMark, NodeMark } from '@bruno00o/graph'
import { Anchor, type GraphState, useGraphState } from '@bruno00o/graph/react'

type Marks = NodeMark<Item> | EdgeMark<Link>

export function Tooltip() {
  const hovered = useGraphState((state: GraphState<string, Marks>) => state.hovered)
  if (hovered?.kind !== 'node') return null
  return (
    <Anchor node={hovered.key} side="right" align="start">
      <div className="tooltip">{hovered.datum.label}</div>
    </Anchor>
  )
}
```

The event props of `<Graph>` are typed from its definition. Components inside it cannot see the definition, so the selector names the marks it reads: see [TypeScript](/docs/typescript#react).

See [Drawing layers](/docs/drawing-layers#anchored-html) for every target and option.

## Hooks

| Hook | Returns |
| --- | --- |
| `useGraph()` | The `GraphInstance`. Throws outside `<Graph>` and `<MapGraph>` |
| `useGraphState(selector, { compare, graph })` | A slice of the graph state. Updates only when the slice changes |
| `useGraphEvent(name, handler, { graph })` | Nothing. Subscribes to an event for the life of the component |

`useGraphState` compares with `Object.is` by default. When your selector builds an object, pass `shallow` from `@tanstack/store` as `compare`.

```tsx
import { shallow } from '@tanstack/store'

const counts = useGraphState(
  (state) => ({ nodes: state.selection.nodes.length, edges: state.selection.edges.length }),
  { compare: shallow },
)
```

`graph.store` is a TanStack Store, so `useSelector` from `@tanstack/react-store` works too.

```tsx
import { useSelector } from '@tanstack/react-store'

const zoom = useSelector(graph.store, (state) => state.view.zoom)
```

The [live statistics from the store](/examples/graph-stats) example reads the view, the hovered element, the selection and the layout with `useGraphState`, and clicks with `useGraphEvent`.

## Outside of Graph

A toolbar, a side panel or a status bar often stands elsewhere in the page than the graph element. Keep the instance in state with the `ref` of `<Graph>` and pass it in the `graph` option of `useGraphState` and `useGraphEvent`, so these components need no portal into `<Graph>`:

```tsx
const [graph, setGraph] = useState<GraphInstance<States, Marks> | null>(null)

<>
  <Graph definition={definition} ariaLabel="Sample graph" ref={setGraph} />
  <Toolbar graph={graph} />
</>

function Toolbar({ graph }: { graph: GraphInstance<States, Marks> | null }) {
  const selected = useGraphState((state) => state.selection.nodes.length, { graph })
  useGraphEvent('layoutend', () => console.log('settled'), { graph })
  return <span>{selected ?? 0} selected</span>
}
```

The option wins over the graph in context. The `ref` is `null` on the first render: `useGraphState` then returns `undefined`, its result type includes `undefined`, and `useGraphEvent` subscribes to nothing. Both follow a graph that changes: they leave the previous one and read the new one. When the graph is destroyed, `useGraphState` keeps returning its last state. Without a `graph` option and outside `<Graph>`, they throw. `S` and `M` come from the type of `graph`, so the selector and the handler are typed without annotations.

`useLegend`, `useTimeline`, `<Minimap>`, `<Legend>` and `<Timeline>` take the same `graph` and accept `null` too: they draw nothing, and their state stays empty, until a graph is given.

## Companions beside the graph

`<Minimap>`, `<Legend>`, `<Timeline>`, `useLegend` and `useTimeline` follow the `<Graph>` around them. To place one elsewhere in the page, pass the graph in its `graph` prop or option. Keep the instance in state with the `ref` of `<Graph>`, so the companion renders once the graph exists:

```tsx
const [graph, setGraph] = useState<GraphInstance | null>(null)

<>
  <Graph definition={definition} ariaLabel="Sample graph" ref={setGraph} />
  <aside>{graph ? <Legend graph={graph} highlight="match" /> : null}</aside>
</>
```

The `graph` prop wins over the graph in context, and `null` waits for a graph, so the `graph ? … : null` test is optional. Without either, the component throws. A new `graph` destroys the companion and creates it again on the new graph.

## Maps

`<MapGraph>`, from `@bruno00o/graph/map/react`, mounts the graph inside a MapLibre map that you create. It takes the props of `<Graph>` without the view, which belongs to the map, plus the `map`, and the `id` and `beforeId` of its layer. It renders no element: its children render where it stands, and the hooks, `<Anchor>`, `<Legend>`, `<Timeline>` and the `ref` work as with `<Graph>`.

```tsx
<MapGraph map={map} definition={definition} ariaLabel="Places and routes" ref={setGraph}>
  <Timeline mode="grow" />
</MapGraph>
```

The entry point does not import MapLibre: pass the map you created. See [Map](/docs/map#react) for the full component, and the [map component](/examples/map-component) example.

## Controlled selection

```tsx
const [selection, setSelection] = useState<ElementKeysInput>({ nodes: [] })

<Graph
  definition={definition}
  ariaLabel="Sample graph"
  selection={selection}
  onSelectionChange={(event) => setSelection(event.selection)}
/>
```

In controlled mode, `onSelectionChange` receives every request, from clicks, the keyboard, the lasso or code, and only the `selection` prop changes the graph. Whether a graph is controlled is decided at mount. See the [selection synced with a list](/examples/controlled-selection) example.

Folded groups, hidden layers and the time window work the same way, with `folded` and `onFoldChange`, `hiddenLayers` and `onLayerChange`, `time` and `onTimeChange`. See the [group tree beside the graph](/examples/group-tree) and the [layers from React state](/examples/layer-toggles) examples.

## Controlled view

```tsx
const [view, setView] = useState<View>({ x: 0, y: 0, zoom: 1 })

<Graph definition={definition} ariaLabel="Sample graph" view={view} onViewChange={(event) => setView(event.view)} />
```

With `view`, `onViewChange` receives the view requests of gestures, keys and `graph.view` calls, and only the `view` prop moves the graph. `<Graph>` renders the state set in `onViewChange` before the frame is drawn, so the view never lags behind the pointer. See [Controlled view](/docs/view#controlled-view) and the [controlled view](/examples/controlled-view) example.
