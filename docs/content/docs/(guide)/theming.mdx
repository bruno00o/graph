## The theme stylesheet

`@bruno00o/graph/theme.css` defines every color the graph uses as a CSS variable, for a light and a dark theme.

```ts
import '@bruno00o/graph/theme.css'
```

The dark theme applies in three cases:

- the root element has the `dark` class,
- or it has `data-theme="dark"`,
- or the system prefers a dark scheme and the root has neither the `light` class nor `data-theme="light"`.

Switching themes rewrites no data on the GPU: the graph resolves its colors again when a class, a `data-theme` attribute, a `style` attribute or the color scheme preference changes.

## Override a token

Set the variables in your own CSS, after the theme. Scope them to any element above the graph.

```css title="styles.css"
:root {
  --graph-node: #3d5a80;
  --graph-cat-1: #0f7173;
}

.dark {
  --graph-node: #98c1d9;
}

.compact-graph {
  --graph-label-background: transparent;
}
```

## Tokens

| Token | Used for |
| --- | --- |
| `--graph-paper`, `--graph-paper-raised` | Page and raised surfaces. The canvas is transparent: the page draws the background |
| `--graph-ink`, `--graph-ink-muted` | Text, hover ring |
| `--graph-node`, `--graph-edge` | Default node fill and edge color |
| `--graph-accent`, `--graph-on-accent` | Selection and lasso |
| `--graph-focus-ring` | Keyboard focus |
| `--graph-halo` | Glow of selected elements |
| `--graph-label-halo` | Halo behind label text |
| `--graph-label-background` | Plate behind labels with `background: true` |
| `--graph-node-ring` | Contour of nodes, ring around badges, default outline color |
| `--graph-badge-fill`, `--graph-badge-ink` | Default badge colors |
| `--graph-cat-1` to `--graph-cat-8` | Categorical color scale. `cat-5` to `cat-1` is the sequential scale |
| `--graph-grid`, `--graph-group-fill`, `--graph-group-line` | Background grid and group surfaces, for your own page |
| `--graph-font` | Font of labels |

See [Theme tokens](/docs/api/theme-tokens) for every value.

## Colors in your options

Any color option takes a CSS color string: a hex value, `var(--graph-cat-3)`, or `color-mix(in oklab, var(--graph-cat-1) 60%, white)`. The browser resolves it, so colors given as variables follow the theme.

```ts
nodes<Item>(items, {
  fill: (item) => (item.weight > 5 ? 'var(--graph-cat-2)' : 'var(--graph-node)'),
  label: { text: 'label', background: 'color-mix(in srgb, var(--graph-paper) 85%, transparent)' },
})
```

## Without the stylesheet

Every variable has a fallback to its light value, so a graph without the stylesheet stays readable. The stylesheet is never injected, which keeps server rendering and content security policies simple.
