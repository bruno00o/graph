## Images

`image` draws a picture inside the node, cropped to cover its shape. Pass a URL, or an object for more control.

```ts
nodes<Item>(items, {
  size: 40,
  image: (item) => ({ src: item.picture, scale: 1 }),
})
```

The fields of the object are listed in [`NodeImage`](/docs/api/nodes#images).

The image sits on the fill, under the contour, clipped by the shape. Return `null` to draw no image for a node. On a [box](/docs/marks#boxes), the image is a square as tall as the box, in its middle and under its label: it suits a box without a label, or one whose label sits outside.

Images load in the background and appear when ready. Each one is stored once, however many nodes use it, in a texture of at most 256 images of 256 by 256 pixels.

The limit is 256 distinct images at once. Images are loaded only when they can be stored, a few at a time, in the order the nodes use them: the others stay as plain nodes, nothing is fetched or decoded for them, and a warning is printed in development. They load as soon as no node uses one of the stored images any more.

So share icons between nodes, a handful of pictures for thousands of nodes costs nothing, and put text in labels, not in images: one image per node, such as an SVG that spells the node name, hits the limit at the 257th node.

## Tinted icons

With `color`, the image becomes a mask: its alpha channel is painted with that color. A single-color SVG icon then follows the theme.

```ts
nodes<Item>(items, {
  fill: 'var(--graph-paper-raised)',
  image: { src: '/icons/circle.svg', scale: 0.6, color: 'var(--graph-ink)' },
})
```

## Badges

`badges` puts a small pill in any corner of the node. Each corner takes a function that returns a badge, or `null` for none.

```ts
nodes<Item>(items, {
  badges: {
    topRight: (item) => (item.weight > 5 ? { text: item.weight } : null),
    bottomLeft: (item) => (item.group === 'A' ? { fill: 'var(--graph-cat-4)' } : null),
  },
})
```

A badge has a `text`, a `fill` and a text `color`: see [`Badge`](/docs/api/nodes#badges).

Corners are `topLeft`, `topRight`, `bottomLeft` and `bottomRight`. A badge is surrounded by a ring of `--graph-node-ring` so it reads on any fill.

Badges sit on the corners of a [box](/docs/marks#boxes), at its full width. A badge is about half the node's diameter, or the height of a box, on screen, up to 18 pixels high. On small nodes, badges hide, and their text appears only once there is room for it. Badges are not picked: a click on a badge reaches the node.

## Outlines and label backgrounds

`outline` draws a ring outside the shape, which separates a picture from its neighbors. `label.background` puts a plate behind the label, which keeps it readable over images and edges. See [Marks and channels](/docs/marks#outlines).

```ts
nodes<Item>(items, {
  image: (item) => item.picture,
  outline: 'var(--graph-cat-1)',
  label: { text: 'label', background: true },
})
```
