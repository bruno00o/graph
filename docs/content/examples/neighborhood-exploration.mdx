## How it works

`createExploration` takes the query client and a function that returns query options for one node's neighbors. It exposes two live sources, `exploration.nodes` and `exploration.edges`, that you pass to `nodes()` and `edges()` like any other data.

A double-click calls `exploration.toggle(key)`. Unfolding runs the query for that node and adds what it returns. Folding removes the elements that no other unfolded node still holds, while the roots and the node itself stay.

`exploration.store` lists the expanded and loading keys. The example copies them into two declared states, `expanded` and `loading`, so progress shows on the graph itself.

## Try it

- Double-click any node to load its neighbors.
- Double-click a node with a thick ring to fold what it unfolded.
- Press the fit button to frame everything loaded so far.

The API is simulated in the page: 2,000 nodes and 8,000 edges, with 250 to 550 ms of latency per request.
